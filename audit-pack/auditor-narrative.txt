This architecture adheres to APPI principles by ensuring personal health information (PHI) is stored exclusively in Tokyo (ap-northeast-1), preventing unauthorized cross-border data transfers. The RDS database resides solely in Japan, with no replication or instances in São Paulo (sa-east-1), as verified by residency proofs. Compute resources in sa-east-1 handle processing via secure TGW peering, maintaining global access without global storage. Placing the database overseas would violate APPI's data localization requirements, risking fines and data sovereignty issues. Audit trails from CloudTrail and WAF logs confirm tamper-resistant monitoring. Network corridors via TGW enforce controlled routing, while CloudFront and WAF provide edge security against direct access. Retention policies with S3 versioning ensure immutability. Overall, this setup prioritizes proof over operation for regulatory compliance.
