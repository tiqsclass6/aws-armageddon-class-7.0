### **Key security controls**

- **Network layer**: **ALB** security group allows inbound HTTPS only from **CloudFront** origin-facing IP ranges (`com.amazonaws.global.**CloudFront**.origin-facing`)
- **Application layer**: **CloudFront** adds `X-Lab2a-Origin-Secret` custom header; **ALB** listener rule forwards only requests with matching header (403 otherwise)
- **Edge protection**: **WAFv2** Web ACL (scope = **CloudFront**) with AWSManagedRulesCommonRuleSet
- **DNS: Route 53** alias records point apex and app subdomain to **CloudFront** (not **ALB**)

## 2. Why **CloudFront** certificate must be in us-east-1

**AWS** enforces that viewer certificates for **CloudFront** distributions **must reside in the us-east-1 region**. This is a global service requirement — certificates in other regions are not accepted for viewer-facing encryption.

## 3. How origin cloaking is achieved (defense in depth)

Two independent layers:

1. **IP-based restriction**  
   **ALB** security group ingress rule uses **AWS**-managed prefix list → only **CloudFront** edge/origin IPs can reach port 443.

2. **Header-based authentication**  
   - Random 40-character secret generated by `random_password`
   - **CloudFront** origin config adds `X-Lab2a-Origin-Secret` header
   - **ALB** HTTPS listener has two rules:
     - **Priority 10:** if header matches → forward to target group
     - **Priority 99:** default/fallback → return fixed 403 response

Even if someone spoofs **CloudFront** IPs, they still need the secret header (which is never exposed publicly).

## 5. Challenges Faced & Solutions

- **ACM empty result**: Certificates were not yet ISSUED → waited for DNS validation to complete
- **InvalidViewerCertificate**: Transient propagation delay → waited 90 minutes after certificate issuance
- **SSL policy error**: Wrong policy name → corrected to `ELBSecurityPolicy-TLS13-1-2-2021-06`
- **WAF scope error**: Created in wrong region → added `provider = **AWS**.us-east-1` to Web ACL resource

## 6. Lessons Learned

- **CloudFront** viewer certificates must be in us-east-1 — non-negotiable
- Wildcard + apex combination is powerful but requires propagation time
- Defense-in-depth (IP list + secret header) significantly raises attack difficulty
- **AWS**-managed prefix lists simplify origin cloaking dramatically
