# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do NOT open a public issue.

Instead:

- Contact the maintainer directly via GitHub profile messaging
- Provide a detailed description and reproduction steps

## Scope

This project focuses on:

- Infrastructure security
- Identity and access management
- Network isolation
- Incident response automation

## Supported Versions

Only the latest main branch is actively supported.

## Disclosure Policy

Validated issues will be addressed promptly, with remediation guidance published where appropriate.
