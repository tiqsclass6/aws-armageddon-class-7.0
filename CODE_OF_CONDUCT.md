# Code of Conduct

## Our Pledge

We are committed to fostering an open, respectful, and professional environment. Participation in this repository is expected to align with industry standards for collaboration, inclusion, and ethical conduct.

## Expected Behavior

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Accept constructive feedback gracefully
- Focus on what is best for the project and the community
- Demonstrate professionalism consistent with enterprise engineering teams

## Unacceptable Behavior

- Harassment, discrimination, or abusive language
- Personal attacks or trolling
- Publishing private or sensitive information
- Conduct that undermines a respectful engineering environment

## Enforcement

Project maintainers are responsible for clarifying standards and enforcing this Code of Conduct. Violations may result in temporary or permanent removal from participation.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, discussions, and external communications related to this repository.
